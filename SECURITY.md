# Security

## Reporting a security issue

If you believe you have found a security issue affecting this website, please report it privately by email to aishwaryasriram2110@gmail.com.

Please do not include sensitive clinical, health, or other confidential personal information in a security report.

This website is a static GitHub Pages site and does not provide user accounts, authentication, file uploads, or a server-side application.

## Scope

The scope includes the public website and its client-side code. Third-party services such as WhatsApp, LinkedIn, Google Fonts, GitHub, and DNS/registrar infrastructure are outside the site's direct application control, although their integration is reviewed for reasonable security hygiene.
